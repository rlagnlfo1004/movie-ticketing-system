# 예매 단위를 수량에서 좌석 지정으로 바꾼다

기존 구현은 상영 하나에 정해진 수량(1,000장)을 두고 Redis에서 숫자를 차감하는 수량 발급 모델이었다. 이 모델은 선착순 쿠폰과 형태가 같아서, 실제 영화 예매에서 생기는 같은 좌석 경합, 결제 대기 동안의 좌석 선점, 선점 만료 같은 문제가 드러나지 않는다. 그래서 사용자가 특정 좌석을 고르고, 좌석 선점 → 예매 확정의 두 단계를 거치는 좌석 지정 모델로 바꾼다. 대가로 좌석 배치, 선점 · 확정 API, 선점 만료 처리를 새로 만들어야 하고, 기존 수량 발급 API와 k6 측정 결과는 그대로 비교할 수 없게 된다.
